# 设计与实现说明

本文档描述 `kindle-pdf-cropper` 的处理流水线、算法与关键实现决策。

## 1. 总体流水线

```
输入 PDF
  │
  ▼
normalize_work_doc()         把每一页的 /Rotate“烘焙”进内容（remove_rotation），
                             统一坐标系 = 显示方向；页面内容原样复制（insert_pdf）
  │
  ▼
Pass 1: 逐页特征提取         渲染灰度位图 → 二值墨水掩码(8×8 块) → 行/列投影；
                             同时提取文本行 bbox/字号、图片框、是否扫描页
  │
  ▼
Pass 2: 全局页眉/页脚判定     跨页统计“重复出现的顶部/底部文本行”（运行页眉/页脚）；
                             逐页结合墨水带间隙启发式，确定 header/footer 裁剪带
  │
  ▼
crop 计算                    从“正文带”投影求内容框，加 padding，
                             排除页眉/页脚带，得到每页裁剪矩形
  │
  ▼
split（可选）                沿水平中轴切为上下两页，两页在切点附近重叠
  │
  ├──► PDF 输出                show_pdf_page(clip) 物理裁剪，文字/矢量/图片保真
  └──► EPUB 输出               固定版式 EPUB3：SVG 页（文字页）/ 位图页（扫描页）
```

## 2. 坐标系统一（关键）

PDF 页面可能带 `/Rotate`（扫描件常见 90°/270°）。PyMuPDF 的 `get_text()`、
`get_image_info()` 返回**未旋转坐标**，而渲染位图是**旋转后的显示坐标**，
两者直接混用会错位。解决办法：

1. `work.insert_pdf(src)` 原样复制页面（保留 /Rotate 与 CropBox）；
2. 对每页调用 `Page.remove_rotation()`，把旋转烘焙进内容；
3. 此后 `page.rect`、渲染位图、文本 bbox 三者使用同一套坐标 = 显示方向，
   裁剪矩形可以直接用于渲染和 `show_pdf_page(clip)`。

## 3. 逐页分析（Pass 1）

### 3.1 渲染与二值化
- 以 `--analysis-dpi`（默认 144）渲染为灰度图；大页面自动降 DPI，最长边不超过 2600px；
- 3×3 中值滤波去除扫描噪点；
- **强墨阈值**：取“明显暗于主背景峰”的像素，取其低分位作为墨色核心，
  阈值放在墨色核心与背景之间约 40% 处，并保证与背景留出最小间隔。
  这样浅灰水印、纸纹、扫描阴影都落在阈值之上被排除，而带暗核心的文字笔画保留。
  （早期中点法会把大片 238 灰的水印/灰纸当墨水，导致投影失效。）
- 暗底页面（负片扫描）仍自动反相；
- 按 8×8 像素块做 `any()` 降采样得到块级墨水掩码；随后用**形态学开运算 + 边界连通块过滤**
  去掉贴边的细长黑边/阴影与孤立污点，避免它们撑大裁剪框。整页深色封面/整版图
  占墨量很大，不会被误删。

### 3.2 文本/图片元数据
- `get_text("dict")`：逐行合并 span，得到行 bbox、字号、归一化文本
  （去符号只留字母数字，用于跨页重复检测与页码识别）；
- `get_image_info()`：图片框与总面积占比；
- 页面分类：`图片面积 ≥ 50% 页面积且文本字符 < 300` → 扫描页；
  文本页/混合页照常走同样的栅格分析。

## 4. 页眉/页脚与页码（Pass 2）

### 4.0 水印 / 重复图案 / 污迹去除（扫描页，Pass 1.5）

浅色水印在强墨阈值阶段已被排除；这里再处理**恒定重复**且可能较暗的图案
（页框、重复站点文字、扫描边），以及正文区域的零星污点。

1. 全书**均匀抽样**（最多 40 页），逐页取该页纸张背景（页内中位灰度），
   对每个像素统计**“比本页背景暗 8 以上的页数占比”**；
2. 占比 ≥ 85% 的像素才判定为水印/运行页眉/页框/扫描边等**重复图案**。
   改用“暗页占比”而不是跨页中位灰度：密集书籍中同一行位置在多页同时出现墨迹时，
   中位灰度会把正文笔画误判为水印并擦掉文字（实测发生）；
3. 该重复图案只用于清理**逐像素行投影**（供自适应切分找空白带），
   **不改动块级墨水掩码**——页眉/页脚文字本身也是重复的，必须在带检测前保留；
4. 保护：某页剔除后剩余墨迹 < 原墨迹 35% 则保留原样；仅对扫描页启用；
   小文档（<4 页）与文字型 PDF 不启用。

### 4.1 全局重复检测（运行页眉/页脚）

两套重复信号，任一命中即把该页顶部小带视为运行页眉：

1. **文本信号（文字型 PDF）**：收集所有页顶部 20% / 底部 20% 区间的文本行；
   排除“页码样式”的行（见 4.2）；统计 `(顶部/底部, 归一化文本)` 出现页数，
   出现 ≥ `max(2, 30%·总页数)` 视为运行页眉/页脚。
2. **条带签名信号（扫描型 PDF，无文字层）**：对每一页的“顶部行状小色带”
   （区域内第一个高度 ≥ 2 块、**且不贴页边**的小带——贴边带是扫描黑边，
   页眉在其下方）做**归一化 16×8 网格签名**（按色带自身对齐）；两个判据任一命中：
   - **聚类**：同一签名出现在 ≥ `max(3, 1%·总页数)` 页；
   - **相邻相似**：与前一页或后一页的签名差 ≤ 25% 位——同一章节的页眉
     逐页相同，**哪怕只有 2 页的章节**也能识别（页眉随章节变化时，
     各变体分别成簇/相邻匹配，阈值不再依赖章节长度）。

### 4.2 页码识别
正则匹配 `- 12 -`、`42`、`Page 12`、`— iii —`、`第 12 页` 等常见形式
（去装饰符后为纯数字、罗马数字或 `Page/第…页` 前缀 + 数字）。

### 4.3 逐页带检测
- **参考行间隙**：文档级全局中位行间隙（pt）。页眉/页脚的分离间隙必须与
  “典型行间隙”比较，而不是与本页唯一的大间隙自比较
  （只有两个墨水组的页面会把页眉-正文间隙误当作中位行间隙）。
- **页眉（顶部）**：顶部行状小带（见 4.1）满足任一条件即裁掉：
  1. `rep_top`（条带签名重复/相邻相似）命中；或
  2. 与下一组的间隙 > 参考行间隙；或
  3. 带高 ≤ ~2.5 行、横向覆盖率 ≤ 50%（居中窄带，且位于页顶 13% 内）——
     兜底规则，用于紧贴正文且无重复信号的情形
     （通栏长标题页眉靠 1 或 2 覆盖）。
- **页脚（底部）**：底部墨水组必须**既小又窄**（≤ ~2 行 / 4% 页高且覆盖率 ≤ 70%，
  典型页码/页脚行），且满足任一：
  1. 与上一组的间隙 > 参考行间隙；或
  2. **跨页重复的窄底带**（`rep_bottom`）：在 ≥3% 页面上位置、高度、覆盖率相近，
     且比正文行窄，并在上一组下方留有一点间隙（≥1 块）。页码常常紧贴最后一行正文，
     纯间隙判据会漏掉，此条按“多页重复出现”识别页脚。
  这样既不会把页末整段正文当页脚，也能裁掉紧贴正文的页码。
- 带边界做“任意墨水”扩张（上限 1.5% 页高），避免细笔画被漏掉。

安全阀：总裁剪高度 ≤ 35% 页高（页眉+页脚+其外侧空白可合理接近 1/3 页）；
若分析掩码几乎为空（墨迹占比 < 0.5%）则整页保留。只有当一个裁剪框在两个方向
都小于 15% 页长时才放弃裁剪——稀疏但真实的页面（章节标题、注释页）
会保留其正确的小裁剪框，而不是回退成整页而留下大片白边。

## 5. 裁剪矩形

- 纵向：从页眉带之下/页脚带之上的区域取墨水掩码；
- 横向/纵向都用**开运算去小污点 + 移除贴边细长连通块**后的掩码测量边界，
  再做极小的质量裁剪（≈0.1%，最多 2 块），使页边黑点/扫描边无法把裁剪框撑到页边；
- 用文本行 bbox、非整页图片 bbox 扩充框体（防止过细/过淡内容被裁）；
- 整页深色封面/整版图（`photo_page`）与空白页保持整页，不做裁剪；
- 加 `--padding`（默认 6pt）安全边距后夹在页面内。

## 6. 切分（--split）

两种策略，由是否指定重叠参数决定。

### 6.1 自适应切分（默认，不指定 `--split-overlap-*`）

目标：把切线放在**两行文字之间的空白处**，因此不会切断任何一行，
两页之间**不需要重叠**（上下两页在切线处无缝衔接）。

1. **文字型 PDF**：取裁剪区内的文本行 bbox，按纵坐标排序，扫描相邻两行的间隙
   `w = next.y0 - prev.y1`；保留 `w ≥ 0.4 × 中位行高` 的候选间隙；
2. **扫描型 PDF / 旋转页 / 任何页面**：图像识别用**逐像素行投影**
   （块级 8px 投影会被相邻行的抗锯齿像素污染，无法分辨紧密排版下
   仅 4-8px 宽的行间空白）。候选空白带必须：
   - 宽度 ≥ `max(2px, 0.5 × 中位行间隙)`；
   - **切线行及其上下各 1px 必须为纯空白**（切线绝对不接触任何墨迹）；
   - **不贴裁剪区边缘**（那是页边距，不是行间隙，会造成半页退化）；
   - 被**两侧均为"实心块"**（行墨水密度 > 85% 且高度 ≥ 6 块）夹住的间隙
     视为图/大公式内部空隙，**优先级最低**——只要别处存在文字间隙，
     就绝不把一张图切成两半。
3. **择优**：按 (是否图内, 距中线距离, 宽度) 排序取第一个同时满足
   “上下两半占比 ≥ 12% 页高”的候选；无合格候选时才退化为中线切分
   （如旋转 90° 的扫描页文字带近乎满页，无水平空白可切）。

实测：对《实变函数 (胡适耕)》264 页扫描书，仅封面页的切线接触墨迹，
其余所有内容页的切线都落在像素级纯空白处；上下两半中位占比 49%。

### 6.2 重叠模式（显式指定 `--split-overlap-pt/--split-overlap-ratio`）

- 沿裁剪矩形的水平中轴切成上、下两页；
- 重叠量 = `max(比例 × 裁剪高, 最小点数)`（默认值 3%/20pt，可用参数调整），
  保证中线附近的一行在上下两页都能完整显示；
- 输出页宽 = 原页宽、页高 ≈ 原裁剪高的一半 → 天然横版（landscape），
  文字仍保持水平方向，Kindle 横屏时字号相当于翻倍。

### 6.3 Kindle 屏幕比例限制（`--max-aspect-ratio` / `--device-type`）

Kindle 横屏时屏幕尺寸为 `Hp × Wp`（`Wp × Hp` 是竖版分辨率），因此横版页面
能在一屏内显示的条件是：

```text
page_height / page_width <= Wp / Hp
```

`Wp/Hp` 就是 `KINDLE_DEVICE_RATIOS` 中的值（3:4 屏为 0.75）。两个选项互斥：

| `--device-type` | 竖版分辨率 | 最大高/宽比 |
| --- | --- | --- |
| `kindle` / `kindle-11` | 1072×1448 | 0.740 |
| `kindle-10` | 600×800 | 0.750 |
| `paperwhite-1` / `paperwhite-2` | 758×1024 | 0.740 |
| `paperwhite-3` / `paperwhite-4` | 1072×1448 | 0.740 |
| `paperwhite-5` | 1236×1648 | 0.750 |
| `paperwhite-12` | 1264×1680 | 0.752 |
| `voyage` / `oasis-1` | 1072×1448 | 0.740 |
| `oasis-2` / `oasis-3` | 1264×1680 | 0.752 |
| `scribe` | 1860×2480 | 0.750 |
| `colorsoft` | 1264×1680 | 0.752 |
| `dx` | 824×1200 | 0.687 |

- `--max-aspect-ratio H/W`：直接给最大高/宽比，取值 `(0, 1]`；
- `--device-type NAME`：按型号查上表；系列名（`paperwhite`/`oasis`）取该系列**最小**比例，
  保证各代都能放下。
- 两者都未指定且处于**交互式终端**（stdin/stdout 都是 TTY）时，`cli.py`
  会用 ANSI 反显 + ↑/↓ 键弹出一个设备选择 TUI（含 "No limit" 与手动输入比例）；
  管道/CI/测试等非 TTY 环境自动跳过。`--device-type none` 可显式表示不限制。
- `--split` 时默认输出文件后缀为 `_split`（否则 `_cropped`），见 `pipeline.process`。

超限时只增加页面宽度（`Segment.width = height / max_ratio`），左右各补
`extra/2` 的空白，`Segment.clip` 不变。因此：

- PDF：新页尺寸为补白后的 `Segment.width/height`，`show_pdf_page` 的目标矩形
  从 `pad_left` 开始，空白侧不拉伸内容；
- EPUB SVG：用补白后的页面尺寸生成 SVG，内容按 `pad_left` 放置；
- EPUB 位图：先渲染 `clip`，再在左右用纸色画布补齐。

## 7. PDF 输出

- 对每个输出段新建一页，尺寸 = 段尺寸（含屏幕比例补白）；
- `show_pdf_page(content_rect, work, src_pno, clip=裁剪矩形)`：
  把源页内容按裁剪区“物理复制”过来，`content_rect` 从 `seg.pad_left` 开始，
  补白区域保持空白。因为是 Form XObject 引用，
  **文字仍是可选中的文字，矢量（表格线/公式路径）和嵌入字体原样保留，图片不重采样**；
- 保留元数据；目录按 `源页 → 输出页` 映射重写。

## 8. EPUB 输出（固定版式）

- EPUB3 `rendition:layout=pre-paginated` + `rendition:orientation=auto`
  + Apple Books `display-options.xml`；
- 每页一个 XHTML，viewport 元数据 = 该页像素尺寸；CSS 用 `width/height:100%` 撑满；
- 页面策略：
  - `--epub-mode svg`：`get_svg_image(text_as_path=False)` 内联 SVG，
    文字保持为 `<text>`，矢量图保持路径，图片 base64 内嵌；
  - `--epub-mode image`：整页 JPEG/PNG 位图（灰阶自动转 L 通道减小体积）；
  - `--epub-mode auto`（默认）：文字页 → SVG，扫描页 → 位图；
- 首段生成封面图；EPUB 校验：`mimetype` 必须是无压缩的首个条目，OPF manifest/spine
  与 zip 内容一致（测试覆盖）。

## 9. 调试辅助

`--debug-dir DIR` 会为每一页输出一张叠加图：
红色 = 被裁掉的页眉/页脚带，绿色 = 最终裁剪框，蓝色 = 切分后的各段框。
调参（padding、zone、gap 系数等）时可直观对照。

## 10. 已知限制与后续方向

- 旋转 90° 的扫描页：页眉/页脚随页面旋转到左/右边缘，目前靠横向边距裁剪覆盖，
  不做列向带检测；自适应切分在该页上找不到水平空白带时会退化为中线切分；
- 双栏/多栏论文只会整体裁剪，不会拆栏（需求限定“只做整体裁剪和切分”，故符合）；
- 扫描页若自带黑色边框/装订阴影，需更大的 `--padding` 或先做去边预处理；
- SVG 页依赖阅读器对 SVG 的支持（Kindle 对固定版式支持有限，建议 Kindle 用户
  使用 PDF 输出或 `--epub-mode image`）；
- 后续可加：OCR 文字层（对接 OCRmyPDF/Tesseract）、斜校正、装订阴影去除、
  多进程并行分析、页眉/页脚自定义区域。
